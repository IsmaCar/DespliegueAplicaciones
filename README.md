# DespliegueCompletoICM

## Descripción 
Este proyecto es un despliegue completo de una aplicación web

## Ejercicio creado por Ismael Carballo Martin

## Servicios utilizados

1. **Frontend**
- React
- Servido en el puerto `3000`

2. **Backend**
- Symfony
- Servido en el puerto `8000`

3. **Base de datos**
- phpMyAdmin
- Servido en el puerto 3306

4. **Servidor Web**
- nginx
- Servido en el puerto 8020
